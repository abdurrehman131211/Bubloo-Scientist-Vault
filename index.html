iPhone / iPad: Open this website in Safari, tap Share, then Add to Home Screen. Enable Open as Web App if shown.

Android: Open the browser menu and select Install app or Add to Home screen.

Computer: In Chrome or Edge, look for the install option in the address bar or browser menu.

Installation options depend on your browser. An internet connection is still needed to sign in and load your vault.
